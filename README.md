# Raso Minang - Complete Stack Application

Rumah Makan Padang "Raso Minang" - Website dengan frontend Next.js dan backend Laravel 11 API.

## 🎨 Design Philosophy (Khas Minang, Bukan Template AI)

### Palet Warna Inspirasi Minangkabau
- **Merah Songket Tua**: `#7A1F2B` - Aksen utama
- **Emas Songket**: `#C9A227` - Aksen sekunder
- **Off-white Hangat**: `#F5EFE2` - Background (sedikit abu-abu hangat)
- **Tinta Coklat**: `#241B16` - Text (bukan hitam pekat)

### Tipografi Karakteristik
- **Headline**: Playfair Display (serif tradisional-elegan)
- **Body**: Inter (sans-serif netral)

### Elemen Visual Khas
- **Gonjong Divider**: Garis lengkung terinspirasi atap rumah Gadang
- **Tidak generik**: Hindari format template AI standar
- **Animasi smooth**: Single entrance animation (tidak fade-up everywhere)

## 🛠️ Installation & Setup

### Prerequisites
- PHP 8.2+
- Node.js 18+
- MySQL 8.0+
- Composer
- npm/yarn

### Backend Setup (Laravel 11)

```bash
cd backend

# Install dependencies
composer install

# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Configure .env with your database credentials
# DB_DATABASE=raso_minang
# DB_USERNAME=root
# DB_PASSWORD=your_password

# Create database
mysql -u root -p
CREATE DATABASE raso_minang;
exit

# Run migrations
php artisan migrate

# Seed sample data (optional)
php artisan db:seed

# Start development server
php artisan serve --port=8000
```

API available at: http://localhost:8000/api/v1

### Frontend Setup (Next.js 14)

```bash
cd frontend

# Install dependencies
npm install

# Configure environment
echo 'NEXT_PUBLIC_API_URL=http://localhost:8000/api' >> .env.local

# Run development server
npm run dev

# Open browser
http://localhost:3000
```

## 📊 Database Schema

### Tables Created by Migrations

1. **branches** - Cabang restoran
   - id, nama, kota, alamat, jam_buka, kontak_whatsapp, is_active

2. **menu_items** - Daftar menu
   - id, nama, kategori, deskripsi, foto, badge, rating, is_active

3. **branch_menu_prices** - Harga per cabang (pivot table)
   - branch_id, menu_item_id, harga, is_available

4. **orders** - Pesanan
   - id, branch_id, status, method, total, customer_name, customer_phone, notes

5. **order_items** - Detail pesanan
   - order_id, menu_item_id, quantity, price, notes

6. **reviews** - Ulasan pelanggan
   - id, branch_id, nama_pelanggan, rating, komentar, is_approved

## 🔌 REST API Endpoints

### Branches
- `GET /api/v1/branches` - List semua cabang
- `GET /api/v1/branches/{id}` - Detail cabang
- `GET /api/v1/branches-with-menu` - Cabang + menu lengkap dengan harga

### Menu Items
- `GET /api/v1/menu-items?kategori=daging&branch_id=1` - Filter menu
- `GET /api/v1/menu-items/{id}` - Detail menu item

### Orders
- `GET /api/v1/orders` - List pesanan (dengan filter status, branch_id)
- `POST /api/v1/orders` - Buat pesanan baru
- `GET /api/v1/orders/{id}` - Detail pesanan
- `PATCH /api/v1/orders/{id}/status` - Update status

## 👤 Admin Panel (Filament)

Untuk setup admin panel dengan Filament:

```bash
# Install Filament
composer require filament/filament:"^3.2-stable"

# Install Filament (interactive)
php artisan filament:install --panels

# Create admin user
php artisan make:filament-user

# Register resources
php artisan make:filament-resource Branch
php artisan make:filament-resource MenuItem
php artisan make:filament-resource Order
```

Admin access: `/admin`
